# Jesús A. Moreno López: personal website

Built with [Astro](https://astro.build). Pages are generated from simple text files.

## Where things live

| What you want to change | File |
|---|---|
| Name, email, links, Bluesky handle, CV PDF | `src/config.ts` |
| Home page bio | `src/pages/index.astro` |
| CV: projects, publications, positions, talks… | `src/data/cv.ts` |
| Science blog posts | `src/content/science/*.md` |
| Variety posts | `src/content/variety/*.md` |
| Videos & interests on Variety | `src/pages/variety/index.astro` |
| Your photo | `public/images/photo.png` |
| Project figures | `src/figures/*.svg` (generated by `scripts/make_figures.py`) |
| Colours & fonts | `src/styles/global.css` (top of file) |

## Writing a post

Create a new file, e.g. `src/content/science/2026-12-01-my-post.md`:

```markdown
---
title: My new post
date: 2026-12-01
description: One sentence that appears in the list.
tags: [epidemics, networks]
draft: false        # set to true to hide it while you work on it
---

Normal text, **bold**, *italic*, [links](https://example.com).

Inline maths $R_0 > 1$ and display maths:

$$ \frac{dI}{dt} = \beta S I - \gamma I $$

![A figure](/figures/my-figure.png)
```

Images go in `public/` (e.g. `public/figures/my-figure.png` → `/figures/my-figure.png`).

## Using a real paper figure instead of a schematic

Put the image in `public/figures/`, then in `src/components/ProjectCard.astro` pass it as
`<ProjectFigure name={p.figure} image="/figures/your-image.png" alt="…" />` (or ask Claude to wire it up).

## Running it locally

```
npm run dev
```
Then open http://localhost:4321. Changes appear instantly.

## Publishing (GitHub Pages)

Every push to the `main` branch rebuilds and publishes the site automatically
(see `.github/workflows/deploy.yml`). One-time setup:

1. Create a GitHub repository named `<your-username>.github.io`.
2. Push this folder to it.
3. In the repo: Settings → Pages → Source: **GitHub Actions**.
4. Set `site` in `astro.config.mjs` to `https://<your-username>.github.io`.
